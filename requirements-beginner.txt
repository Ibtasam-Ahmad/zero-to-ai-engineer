# =============================================================================
# requirements-beginner.txt  -  a small, CPU-only install for this course
# =============================================================================
#
# WHAT THIS IS
#   A short list of the core libraries that the beginner and core notebooks
#   use (Python basics, data analysis, machine learning, deep learning, NLP,
#   LLM basics, FastAPI, maths). It is meant for Windows, macOS and Linux and
#   runs those notebooks on a normal CPU - no GPU and no API keys needed.
#
#   The big requirements.txt in this folder pins every package used anywhere
#   in the repo (about 280 packages) and needs Python 3.12 or newer.
#   Start with THIS smaller file instead, and add the few extras a module
#   needs when you reach it (see the table in LEARNING_PATH.md).
#
# TESTED WITH
#   Python 3.10 and Python 3.12 (fresh virtual environments, CPU only,
#   tested on Linux). Python 3.11 sits between the two and is expected to work.
#   Python 3.9 or older is NOT supported (several libraries below need 3.10+).
#   pip picks slightly different versions for 3.10 and 3.12 inside the ranges
#   below - that is expected and fine.
#
# HOW TO INSTALL (copy these lines into a terminal, inside this folder)
#
#   1. Create a virtual environment (a private box for this course's packages):
#        Windows:       py -3.12 -m venv .venv
#        macOS/Linux:   python3 -m venv .venv
#
#   2. Turn it on ("activate" it):
#        Windows:       .venv\Scripts\activate
#        macOS/Linux:   source .venv/bin/activate
#
#   3. Install everything (downloads about 600 MB and uses about 2.3 GB of
#      disk; 5-40 minutes depending on your internet speed):
#        python -m pip install --upgrade pip
#        pip install -r requirements-beginner.txt
#
#   4. Start Jupyter and open any notebook:
#        jupyter lab
#
# ABOUT THE PYTORCH LINE BELOW (--extra-index-url ...)
#   The line "--extra-index-url https://download.pytorch.org/whl/cpu" tells pip
#   to fetch the small CPU-only build of PyTorch (about 200 MB). On Linux the
#   default PyTorch from PyPI bundles several GB of NVIDIA GPU files instead.
#   - Linux and Windows users: keep it (on Windows it simply gives the same
#     CPU build you would get anyway).
#   - macOS users: you can delete that line - the normal macOS build already
#     runs on the CPU (and on Apple-silicon GPUs). Keeping it should also work.
#   - Have an NVIDIA GPU and want to use it? Delete that line, then follow the
#     install command for your system at https://pytorch.org/get-started/locally/
#
# OPTIONAL EXTRAS
#   Some advanced notebooks use extra libraries (e.g. opencv, faiss, nltk,
#   spacy, mlflow, gymnasium, openai). If a notebook stops with
#   "ModuleNotFoundError: No module named 'xyz'", install that one library
#   into the same environment, for example:
#        pip install faiss-cpu opencv-python-headless nltk
#   (the pip name is sometimes different from the import name:
#    cv2 -> opencv-python-headless, faiss -> faiss-cpu, sklearn -> scikit-learn)
#   A few notebooks call paid AI services and need an API key
#   (OPENAI_API_KEY, ANTHROPIC_API_KEY, ...). You can still read them.
# =============================================================================
